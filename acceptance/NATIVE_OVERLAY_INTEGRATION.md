# Native overlay integration (source, no commit)

Runtime now consumes the preserved three-slot operands rather than the lossy image vector. Slots retain decoded raw dimensions; wildcard/empty operands clear their slots. Second slot filters raw background preparation; third filters individual raw stage extras before placement/camera crop, and supported character surfaces during composition. First slot is retained and saved but deliberately inert: bank1 authored ownership remains unresolved. Production overlay resources never enter the historical source-over overlay_layers vector. That vector remains only for legacy saves/test sentinels.

StageEffectLayers keeps original base/extras/foreground; overlay changes rebuild from originals immediately, preserving current camera and foreground order. WScroll uses the same filtered copies without changing its geometry/timing. Character caches remain raw. Mouth/blink patches are filtered on local copies using parent sprite row coordinates rather than arbitrary independent patch bottom alignment; native animation integration ordering is not independently runtime-verified.

Manual saves now write version7 with a new native_overlay field containing raw slots and original stage inputs. Explicit eight-field v6 tuple migration was added; v4/v5 migrations retained. Restored viewport/source stay authoritative until an explicit overlay change; effect timers/dynamic motion are not newly persisted. Legacy source-over saves cannot recover original slot identity.

Validation: required `source "$HOME/.cargo/env" && cargo test --all-targets --quiet`:119 library passed,11 ignored;1 CLI passed. All11 ignored tests passed with MINORI_EF_ROOT and EF_GAME_ROOT pointing to the installed ef game. New actual-gym regression loads bgc_sch006a01_00_stm.png + stm_kei06f01.png at200 with or_kei00a.png, checks exact raw-extra filtering, >100000 untouched background pixels, repeated stage/overlay idempotence, clear exact restoration and serialized slot restore. Synthetic regressions cover second/third separation, foreground retention, clear reversal, untouched originals, character/animation-patch coordinates. v6 migration regression passes.

Limits: no first-slot scope guess, no screen/HSV implementation changes, no original executable dynamic oracle, no general equivalence claim. Existing freeze_characters destructively bakes characters into cropped background_rgba without updating raw stage ownership; later camera/effect/overlay recrop may discard these frozen pixels. This patch does not reconstruct frozen ownership. Existing cutin/shake/particle timing and screen transfer behavior remain unchanged; these dynamic states are not comprehensively represented by static save snapshots. Source-sized clones cost memory/time; no new filtering cache was introduced. Native per-name overlay overrides and unsupported crop/scale ordering are not newly reconstructed. Parent owns visual baseline inspection.
